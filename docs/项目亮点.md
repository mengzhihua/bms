# BMS 亮点

BMS 把仓储、运输、订单单据变成应收应付。计费规则在合同里，不在控制塔里临时拍。

1. **一张费率能表达多种算法。** 按单、行、件、箱、托、重量、体积、里程和天计，计价可以是固定、单价、整段阶梯或分段累进，并带最低、最高收费和优先级。
2. **上游单据按来源加外部单号幂等接入。** 仓储、运输、订单推送，CSV 导入和手工录入进同一套计费。重复推送不会再出一张费用。
3. **从费用走到钱。** 对账单可以在草稿期调整，之后确认、争议、结清；发票登记校验对账单余额；收付款可以核销和反核销。
4. **经营数从同一套费用出来。** 工作台给待计费、本月应收应付、逾期和即将到期合同；报表给毛利、账龄和结算对象台账。
5. **给控制塔的是成本，不是第二本账。** 控制塔按日期拉未作废费用。它不能在这里改费率、冲销或核销。订单上已有结算运费时，控制塔汇总优先用这笔。
